# 35 - Properties, Getters & Setters

## 🎯 Objective

Learn how to safely access and modify object attributes using Python properties.

Instead of directly exposing attributes, properties allow validation and controlled access while keeping the code clean and Pythonic.

## 📚 Topics Covered

- Why Getters and Setters?
- The @property Decorator
- Getter Methods
- Setter Methods
- Read-only Properties
- Validation
- Best Practices

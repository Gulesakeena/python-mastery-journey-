# 40 - Polymorphism

## 🎯 Objective

Learn how the same interface (method or function) can perform different behaviors depending on the object.

Polymorphism is one of the four pillars of Object-Oriented Programming (OOP) and makes code flexible, reusable, and extensible.

---

## 📚 Topics Covered

- What is Polymorphism?
- Method Overriding
- Duck Typing
- Built-in Polymorphism
- Operator Overloading
- Runtime Polymorphism
- Practical Examples

# 42 - Dataclasses

## 🎯 Objective

Learn how Python's `@dataclass` decorator simplifies class creation by automatically generating methods such as `__init__`, `__repr__`, and `__eq__`.

Dataclasses are widely used in modern Python applications, including FastAPI, backend systems, AI applications, and data modeling.

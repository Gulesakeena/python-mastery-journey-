# 37 - Pass by Object Reference (Call by Sharing)

## 🎯 Objective

Learn how Python passes arguments to functions.

Understand why Python is **neither pass-by-value nor pass-by-reference**.

Master Python's **Call by Sharing (Pass by Object Reference)** model.

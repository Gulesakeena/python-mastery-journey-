# 39 - Inheritance

## 🎯 Objective

Learn how classes can inherit properties and methods from other classes.

Inheritance is one of the four pillars of Object-Oriented Programming (OOP) and promotes code reuse, extensibility, and maintainability.

---

## 📚 Topics Covered

- What is Inheritance?
- Why use Inheritance?
- Parent (Base) Class
- Child (Derived) Class
- The `super()` Function
- Method Overriding
- Types of Inheritance
- Method Resolution Order (MRO)

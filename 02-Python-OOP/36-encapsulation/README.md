# 36 - Encapsulation

## 🎯 Objective

Learn how Encapsulation protects object data by controlling access to attributes and methods.

Understand the difference between:

- Public Members
- Protected Members
- Private Members
- Name Mangling

Also learn why Python does not have true private variables like Java or C++.

---

## 📚 Topics Covered

- What is Encapsulation?
- Public Members
- Protected Members (_)
- Private Members (__)
- Name Mangling
- Data Hiding
- Best Practices

## Interview Challenge

Build a Smart Home System.

Classes

- SmartDevice (Abstract)
- SmartLight
- SmartFan
- SmartAC

Requirements

- Create an abstract method `turn_on()`.
- Create another abstract method `turn_off()`.
- Each child class should implement both methods differently.
- Store all devices in a list.
- Iterate through the list and call both methods.
- Explain why abstraction is useful in this design.
